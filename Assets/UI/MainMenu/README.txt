ARCADE MAIN MENU UI KIT
=======================

Style: dark arcade, yellow + black + white
Format: PNG, transparent backgrounds where appropriate

FOLDERS
- background/: full-screen main menu background
- buttons/: EACH button is an individual PNG file
- icons/: individual utility icons
- panels/: settings, credits, confirmation, pause and blank panels
- decoration/: chevrons and crosshair
- preview/: composed example main menu

UNITY IMPORT
1. Extract this ZIP.
2. Copy the folders into Assets/UI/ArcadeKit/.
3. Select PNG assets in Unity and set Texture Type to Sprite (2D and UI).
4. Use Image components for backgrounds, buttons and panels.
5. For buttons, use each individual PNG as the Source Image.
6. Set the background Image to Preserve Aspect if needed.

NOTES
- Button assets are separate files, not a combined button sheet.
- PNG transparency is used for buttons, icons, panels and decorations.
- The preview is a visual reference; build the actual interactive menu with Unity UI.
